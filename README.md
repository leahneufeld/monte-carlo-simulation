# Monte Carlo Simulation & Statistical Error Analysis
Python Monte Carlo simulation for numerical estimation, regression analysis, and error visualization.
## Technologies Used
- Python
- NumPy
- Matplotlib
- Random sampling
- Regression analysis

## Methodology
- Generated random points to estimate the area enclosed by a cardioid.
- Compared Monte Carlo estimates with the theoretical area.
- Evaluated estimation error across sample sizes ranging from 100 to 10,000.
- Used regression analysis and visualizations to investigate convergence.
- Explored the volume of a rotated cardioid.

## Results
- Investigated how estimation accuracy changes with sample size.
- The project report presents a log-log regression slope of approximately -0.48, close to the theoretical value of -0.5.
- Compared simulated estimates with analytical calculations.
